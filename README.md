# IntelliFlow Smart Traffic

AI/ML-based smart traffic prediction and management project.

## Machine Learning

This project uses machine learning for traffic prediction.

### ML Files

- `IntelliFlow_Traffic_Prediction.ipynb` – ML notebook
- `features.py` – Feature engineering
- `models/` – Trained ML model
- `encoders/` – Preprocessing encoders
- `metadata/` – ML metadata
- `requirements.txt` – Required Python libraries
